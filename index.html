Chat – Domain 2

Enter the values you want to pass into imichatwidget.init(...) when you click the chat bubble.

Leave blank if you are starting a brand new chat and do not want to resume any thread.
Select existing if you want your flow to attempt resuming/associating with a prior thread.

Tip: You can change these values anytime before opening the chat bubble. The values present when the widget is ready will be passed into init.
